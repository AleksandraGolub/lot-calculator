# Калькулятор лота — Bullwaves

Одностраничный калькулятор размера позиции для MT5 (Bullwaves, Equitex Capital): считает от своих денег (баланс + плавающий), включает спред и комиссию, проверяет маржу и суммарный риск книги.

Открыть: https://aleksandragolub.github.io/lot-calculator/

10 тикеров: XAUUSD!, XAGUSD, NDXUSD!, DAXEUR!, EURUSD!, GBPUSD!, AUDUSD!, NZDUSD!, USDCAD!, USDCHF!, USDJPY!.
Для DAXEUR! $ за пункт = €10 × курс EURUSD, поэтому нужен курс евро.

Котировки: золото онлайн, форекс — суточный курс, индексы вводятся вручную.
